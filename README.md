
# larp.OS

**A modern Linux distribution based on Arch Linux.**

larp.OS is a custom Linux operating system designed to deliver a complete, modern and ready-to-use desktop experience.

## Vision

Build an independent Linux distribution that is ready to use immediately after installation, without requiring users to configure Arch Linux manually.

## Features

- Arch Linux foundation
- Custom graphical desktop
- KDE Plasma
- Wayland support
- Custom boot animation
- Custom login screen
- Preconfigured desktop environment
- Graphical installer
- Network and Bluetooth support
- Security and performance optimization
- Developer tools

## Desktop Experience

larp.OS will boot directly into a fully configured graphical desktop.

No manual terminal setup required for everyday use.

## Technologies

- Arch Linux
- KDE Plasma
- Wayland
- systemd
- SDDM
- Calamares
- archiso
