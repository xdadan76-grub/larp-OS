 
# Contributing to larp.OS

Thank you for your interest in contributing to larp.OS!

## Project

larp.OS is a custom Linux distribution based on Arch Linux.

Our goal is to create a complete, modern and user-friendly operating system.

## Development Rules

- Keep the system stable and secure.
- Follow Arch Linux best practices.
- Write clean and documented code.
- Test changes before submitting them.
- Do not introduce unnecessary dependencies.
- Do not remove existing features without approval.

## Contributions

Contributions are welcome in:

- Desktop environment
- System configuration
- Installer
- Applications
- Security
- Performance
- Documentation

## Pull Requests

All changes must be reviewed before being merged.
